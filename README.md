# 小步學英文｜第十六版：A4 筆記與教材快速查找

在第十五版教材基礎上調整，不刪除既有單字、文法、閱讀、聽力或練習卷。

## 這次新增

1. **筆記切換**：共 1,200 個學習單元，使用「每 100 單元」範圍下拉、單元下拉以及搜尋欄，可依單元編號、文法主題、英文或中文查找；上一單元、下一單元可直接切換。
2. **課程跳轉**：「今天學習」內新增可展開的課程單元選擇器，可以看到全部 1,200 單元並分段跳轉。
3. **文法庫**：原有關鍵字搜尋搭配「學習程度」下拉篩選。
4. **閱讀與聽力**：原有難度分類之外，新增文章搜尋與排序下拉。
5. **練習卷**：100 回依原有四大類顯示，新增文字搜尋及「直接跳至指定練習卷」下拉清單。
6. **A4 列印**：筆記採 A4 直式、文法在前、單字另起頁；長內容自然跨頁，同一單字盡量不切開；移除多餘的頁面裝飾與尾端孤立勾選框。因筆記內容詳細，每單元不固定只印 2 張，實際頁數依內容而定。
7. **小修正**：修正閱讀／聽力首頁的顯示文字錯誤。

## 更新 GitHub Pages

### 第十五版更新到第十六版（推薦使用快速更新包）

把 `index.html`、`styles.css`、`app.js`、`README.md` 四個檔案，上傳到原有 GitHub 儲存庫根目錄覆蓋同名檔案，提交至 `main`，等待 GitHub Pages 發布即可。既有 `data.js`、`papers` 等教材檔案不需重新上傳。

如果現在網站不是第十五版、或之前漏傳過教材，請使用第十六版完整網站 ZIP，整包解壓後上傳網站根目錄，`papers` 資料夾必須保留結構。

### A4 列印建議

在「查教材 → 我的英文筆記」選定單元，按「列印 A4 筆記」。列印設定請選 A4、直式、縮放 100%，關閉瀏覽器預設頁首／頁尾。文法與單字筆記可能分成多張紙；這樣能保留完整說明及足夠字級，不必縮到過小或截斷內容。

### 學習紀錄

本次不變更 `localStorage` 儲存鍵（`toeic-smallsteps-v5`）與資料結構；在相同瀏覽器、同一 GitHub Pages 網址下應沿用原有進度。沒有新增資料備份或獨立複習頁。

### 注意事項

網站程式不含資料庫，無法自動跨裝置同步。新增的搜尋／篩選不會變更、刪除單字及原有學習作答紀錄。

## 學習方式

首頁仍然只提示一個小單元；文法一次兩個相關主題，搭配五個單字、語句例子及手寫式筆記。完整教材可自由查詢，但不會一次要求背完。閱讀、聽力每篇五道理解題；練習卷每次先顯示十回，可按「再看 10 回」繼續找。筆記採用上文法、下單字的完整格式，包括定義、規則、正反例、已知例句、詞形、單字搭配及抄寫空間。

字首／字根／字尾／字族仍與原有詞庫連接；擴充後的新字有 `base_word` 原形標記可供查詢。字根分類由前一版的索引延用，新增 3,000 條目不保證全部已被正確歸入可靠詞根，無法確定時不硬填。

## 部署 GitHub Pages

原網站：<https://coco11465002.github.io/toeic-learning/> ；儲存庫：<https://github.com/coco11465002/toeic-learning>。

1. 將第十五版完整 ZIP **解壓縮**。
2. 把解壓後**根目錄的所有檔案**和**整個 `papers` 資料夾**更新到 `toeic-learning` 儲存庫 `main` 分支根目錄，保留 `index.html` 於根目錄；同名檔案需取代舊版。
3. 提交變更後，GitHub Pages 將依既有設定自動部署；不必另開新儲存庫，舊網址不變。
4. 網站只存於使用者目前瀏覽器的 `localStorage`（鍵值 `toeic-smallsteps-v5`）。普通重新整理不應主動清空；換瀏覽器或清除網站資料可能遺失紀錄。依使用者要求，網站不顯示「備份」與「獨立複習」工具。
