# TOEIC 小步學｜第九版：3,000 字詞完整分類圖鑑

## 這次改了什麼

- 保留原本完整 3,000 筆字詞、59 個文法主題、600 個小單元、既有習題與 PDF 練習卷。
- **3,000 / 3,000 筆詞庫字詞都有分類入口**：每個字詞至少歸到原本的 26 個情境主題之一。
- 目前 **941 筆**可額外連到以字首、字根、字尾、衍生詞形整理的學習組；其他 **2,059 筆**暫時保留在情境主題歸檔，不能因字母相似就硬說同一詞根。
- 分類共 **423 組**：8 個字首、10 個字根、15 個字尾、364 個同字族組、26 個主題歸檔組。數量是目前自動生成加人工整理的索引規模，不代表全部已通過語源學者逐字校訂。
- 取消字族每組最多 4 字的限制：每組列出所有在現有詞庫找到的字詞，預設一次顯示 **8 個**，可再看 8 個或手動展開整組。
- 支援搜尋英文、中文或字根；可從分類進入單字詳解，再從單字詳解跳回所屬字根／字族／主題。
- 只有前版教材的補充詞但尚未收進 3,000 字詞庫時，另列「詞庫外補充」，**不混入已收錄字數**。
- 保留原版配色與筆記、文法及進度儲存方式；原始 ZIP 中的 20 份 PDF 維持不變。

### 分類限制與教學提醒

「字尾相似」不必然等於「共享語源」。本版的擴充採取較保守的詞形連結，但仍包含程式化初步整理的群組，**不是已由語言學辭典逐一核定的語源對照表**。若無足夠構詞依據，就只以主題整理。不同詞性和字義仍應以例句確認；若發現誤分的字族，應在後續修訂時逐筆更正。

## 使用與限制

- 不需要登入帳號；課程與 PDF 在 GitHub Pages 直接使用。
- 英文朗讀依賴裝置與瀏覽器的 Web Speech 語音引擎，無法保證每台手機都有相同口音或支援全部語音。
- 學習進度保存在 **同一台裝置、同一個瀏覽器的 localStorage**，不會自動跨手機和電腦同步。更新網站通常不會刪除相同版本的進度，但從第四版升級到第五版使用新記錄方式，舊版進度不保證繼承。
- 拆分是拼字輔助記憶，不等於正式音標、真實語源字根，且仍有必要進行字詞音節的人工校訂。
- 部分單字目前只有常見搭配、詞性、中文或短語，尚未逐筆配齊完整而獨立的真實情境例句；若無可靠翻譯，介面會標示「中文說明待補」，避免編造。
- 部分詞條的中文定義來自 ECDICT 開放字典，必須逐步校訂語境和詞性。原始教材中如有翻譯不自然或錯誤，以後續校訂版為準。
- 所有基礎練習卷為自行編寫的學習題，不是 ETS 官方題，也不是考古題。正式 TOEIC 題型教學會在基礎學習完成後再另行規劃。

## 第七版：完整筆記與雙主題單元（2026-11）

- 每個小單元不再只有單一文法主題，改成 **2 個相關文法主題＋3 個關鍵觀念＋5 個單字**。學習路線仍每次拆成短步驟，不會同時塞進大量新詞。
- 文法練習頁顯示兩個主題及至少三個觀念；例句頁會收錄兩個主題的例句，線上小練習也涵蓋兩個主題。
- 筆記改成更長的學生手寫課堂筆記：主題 A/B 的基本講解、三個重點規則、四個中英例句、兩個主題各自的易錯提醒、兩題中翻英、自由手寫區。
- 單字筆記同樣擴充，每字附中文、詞性、拼字分段、已有的常見搭配／例句、可查到中文的近義字、自己造句的空間。**原資料尚未校對補齊者不會虛構內容。**
- 筆記仍維持 **上下排列**，上文法、下單字。列印時允許內容自然分頁，避免筆記變長後被 A4 裁掉。
- 沿用原進度儲存鍵 `toeic-smallsteps-v5`，更新既有 GitHub Pages 無需重新設定或清除進度。
- 升級已使用第六版上下筆記的網站時，只需更新 `app.js`、`styles.css`、`index.html`（若想同步最新版資源查詢參數）與 `README.md`。其他字庫、課程資料與 PDF 不需變動。

## 第八版：字根・字族、真正例句、標色與間隔複習（2026-11）

這次以「教材增量，但每一次只學少量」為原則，**保留原本的 3,000 筆單字、59 個文法主題、每單元 2 個相關文法主題／5 個單字／基礎練習題，以及既有 PDF 練習卷**。

### 新增功能與修正

- **導覽列新增「字根・字族」**：目前有 39 組主題，包括 8 個常見字首、10 個字根、8 個字尾，以及 13 個實用字族。每組先學 4 個相關字、聽發音、翻開中文，再做一題回想練習。
- **新增 `enrichment.js` 教材**：為 199 個常用詞條補充合計 567 句人工編寫的完整英文例句及繁體中文翻譯；並為其中部分單字補充 132 組雙語常見搭配，以及可靠的近義、反義、易混淆詞與字族詞。
- **減少假資料**：原本大量 `Today we are learning the word ...` 只是介紹詞彙，不再算作實際用法例句；像 `book` 的「動詞；看例句中的動作與受詞位置」等不具教學價值的自動提示，不再顯示。未確認的近反義詞不以「沒有可靠的常見直接同義詞」佔據學習介面；也不以任意相似字代替有根據的詞彙關係。
- **補充其他詞彙的例句**：在 567 句人工編寫例句、既有文法例句與原有經檢查的完整句中尋找能直接示範目標單字的句子，重用已附中文翻譯的自然情境；仍沒有合適句子的字不編造句子。
- **重要單字與文法標色**：教學例句、單字詳解、文法庫及學生手寫筆記中的關鍵形式會用螢光色標示；朗讀按鈕可播放整句。動詞會盡可能標示 `book / books / booked / booking` 等實際形態。
- **筆記內容增加**：保留上下排列（上文法、下單字）；文法部分收錄最多六句例句及中文，單字筆記每個字最多有兩句已完成的用法例句、搭配、詞性、拼字拆分與自行造句空間。
- **間隔複習**：首頁新增「先複習」入口；完成一個小單元後，系統將那 5 個單字安排於隔天複習。回答「我記得」之後延長至 3、7、14、30 天；「還不熟」則隔天再看。舊版已完成單元會在首次升級時加入待複習清單。複習記錄與原本進度都保存在同一個瀏覽器的 `localStorage`。

### 教學方法參考

- British Council, [Word building](https://learnenglishteens.britishcouncil.org/exams/grammar-vocabulary-exams/word-building)：同字族、詞性轉換、透過一組字理解更多字。
- British Council, [Word Family Framework](https://494f9c0dda672f79b2ee-6b9e395a7343d6a0b8b7ac609388ce35.ssl.cf1.rackcdn.com/wff/index.html)：以詞族而非孤立的字詞學習詞彙。
- Carpenter et al. (2022), [The science of effective learning with spacing and retrieval practice](https://www.nature.com/articles/s44159-022-00089-1)：間隔學習與主動回想的研究綜述。
- Cambridge Dictionary, [book](https://dictionary.cambridge.org/dictionary/english/book)：區分名詞「書」和動詞「預訂」的用法。教材例句為自行撰寫，未抄錄詞典例句。

### 仍待逐步校訂的內容

3,000 筆字詞中的**每一筆**尚未都有 2–3 個完整獨立例句、詞族與經人工確認的近反義字；本版的人工補充範圍是 **199 個詞條／567 句新例句／132 組搭配**。其他條目可利用已校訂、真正包含該字的句子提供教學，但不把內容不相干的關係硬填進去。拼字拆分不是字源分析；字根教學區提供另外核對過的構詞關係。更新目前不會在 GitHub 上自動部署，仍需使用者提交更新檔。
