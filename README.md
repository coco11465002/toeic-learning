# TOEIC 小步學｜GitHub Pages 第三版

一個給英文基礎較弱的學習者使用的純靜態多益學習網站。無須註冊、登入或付費伺服器；手機和電腦皆可使用。

## 發布或更新 GitHub Pages

1. 解壓縮 ZIP 檔。
2. 將 **7 個檔案**（`index.html`、`styles.css`、`updates.css`、`app.js`、`data.js`、`README.md`、`LICENSE-ECDICT.txt`）上傳至 `toeic-learning` Repository **根目錄**，並覆蓋舊版本。
3. GitHub **Settings → Pages → Build and deployment** 選 `Deploy from a branch`、`main`、`/(root)`，再按 Save。
4. 等待網站發布後，打開 https://coco11465002.github.io/toeic-learning/ 。若還是舊畫面，重新整理或稍後再試。

也可以在電腦上直接開啟 `index.html` 測試主要功能。發音採用瀏覽器內建 Web Speech API，依瀏覽器、作業系統及可用聲音而有不同；部分環境需連線才能使用聲音。

## 學習安排

1. **基礎文法和常用字**：從詞性、句子、be 動詞、第三人稱與單複數開始。
2. **時態與字詞變化**：學會如何選擇動詞形式，搭配單字詞族學習。
3. **商務情境例句**：透過工作、會議、訂單和服務等詞彙建立閱讀能力。
4. **多益題型與模擬測驗**：留待前面三階段熟悉後，再進行正式題型學習。

全站共有 **3,000 個不重複字詞**、**20 堂文法課**和 **300 個單元**，每單元安排一堂文法課（課程會安排複習）、10 個字詞、例句或常用搭配及手寫筆記。網站原有的模擬練習程式保留作為日後第四階段教材，但目前不在主導覽列中，也不要求在前三階段先做考題。

## 第三版改動

- 返回鍵與瀏覽器返回鍵均依實際瀏覽紀錄逐層返回。例如「練習 → 單字 → 文法」可一頁一頁退回。
- 修正頂部「學習」導覽，並支援 `#path`、`#grammar`、`#words` 等網址直接開啟。
- 背景改成紫色、薄荷綠、蜜桃色的柔和漸層；主要功能以四色小卡呈現。
- 文法頁預設只展示核心觀念和少量例句；其他規則、句子及筆記可自行展開。
- 單字清單每次先顯示 8 張；可搜尋、播放單字和英文搭配、展開詳細比較資料，或進入「單一單字專注畫面」。
- 單字每筆均有拼字拆分、同／近義、反義／對比詞、混淆詞、字根詞族欄位與常見搭配；沒有可靠直接對應時會清楚標記，不會亂造關係。對比詞不一定是嚴格語義上的反義詞。
- 經人工編寫的情境例句 **142 筆**，另有從既有單字資料整理的 **850 筆常見英文搭配短語**。其餘單字目前只有清楚標記的認字提示，**不會假裝是完整的用法例句**，後續仍需逐批編修。
- 朗讀按鈕直接放在文法、單字、例句卡片內；可切換美式／英式及語速。
- 學習進度只儲存在目前瀏覽器的 `localStorage`，**不同手機／電腦之間不會自動同步**；清除瀏覽器資料也會失去進度。
