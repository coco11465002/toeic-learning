# TOEIC Learning｜多益英文學習平台

可直接發布至 GitHub Pages 的純靜態學習網站，不需登入或後端服務。

## 使用方式

1. 直接開啟 `index.html`，即可在支援的瀏覽器中使用。
2. GitHub Pages：將此資料夾內檔案上傳到儲存庫根目錄，於 GitHub **Settings → Pages → Build and deployment → Deploy from a branch** 選擇 `main` 與 `/(root)`。
3. 開啟 `https://你的帳號.github.io/儲存庫名稱/`。

語音播放使用瀏覽器的 Web Speech API，因裝置、瀏覽器與安裝語音而異。題目為自編練習，非 ETS 官方試題。

## 新版功能

- 3,000 個不重複單字：原書 621、首版補充 343、常用字庫增補 2,036。
- 每個單字都有拼字拆分欄位。單音節字不會強行拆成錯誤的音節；拼字拆分僅為輔助記憶，不等於 IPA 音標。
- 20 堂文法課，可前後切換，內容從詞性、主詞、be 動詞到多益基本文法。
- 300 個循序單元，每單元 10 字、文法課、單元自測與手寫筆記連結。
- 單字專注模式，每次僅顯示一字；點擊後才展開中文與用法。
- 頁面「返回上一頁」及瀏覽器上一頁功能。
- 單元進度只儲存在目前裝置的瀏覽器中；不需要登入，也不會跨裝置同步。

## 資料更新

- `data.js`：單字資料（由原始 626 筆含重複詞條與補充字整理）。
- `app.js`：文法課程、練習題與網站互動。
- `styles.css`、`updates.css`：視覺樣式。

此版有 3,000 個字詞、20 堂文法課、每組 10 字的循序學習模式以及自編題目。第一版已經有的深入欄位（固定搭配、字根詞族、同義詞等）保留；新增的 2,036 個常用字先提供中文、詞性及拼字拆分，部分深入欄位仍須逐批校訂補充，避免不正確的詞義搭配。

資料來源：新增常用字部分使用 [ECDICT](https://github.com/skywind3000/ECDICT) 公開英中字庫，並以程式選出常用詞，從簡體中文轉為繁體中文。字義與分類供學習參考；完整 MIT 授權文字見 `LICENSE-ECDICT.txt`。
