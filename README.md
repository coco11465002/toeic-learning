# TOEIC 小步學｜第十版：完整字族發現與每字分類標示

這次修正第八版「今天的發現」只顯示四個示範字，以及第九版字族回想練習只取前四個字的問題；並補上每個單字的分類入口。

## 第十版重點

- **「今天的發現」不再限四個字。** 點開任何分類會列出該組目前詞庫內**實際符合的全部字詞**。少於 25 個字的分類直接全列，較大的分類先列 12 個，可逐次再看 12 個，或按「一次展開本組全部」；展開後也能收起。
- 每一組顯示總收錄數、目前顯示數，支援在單一分類內搜尋英文及中文。某組若確實只有 2–4 個已收錄字，會標明是詞庫資料現況，而不是介面截斷；不會為湊數列入不相干的字。
- **字族回想練習會輪流練習組內每個字**，不再只使用前四個字組題。仍然一次只做一題，以降低學習負擔。
- **每個單字顯示所屬分類。** 單元的單字專注卡（翻開中文前也可看）、獨立單字詳解頁、單字庫小卡、間隔複習畫面、文法／單字手寫筆記中的單字頁，皆可看到分類資訊。
- 在單字學習卡與詳解頁，可點「字首／字根／字尾／同字族／主題」標籤，直接跳到對應的分類頁，並可使用返回鍵回到原本的學習位置。
- **類別有分清楚：**「同字族」「字首」「字根」「字尾」是詞彙構詞學習用的關係；「主題」只表示使用情境，**不代表相同字根**。未有可靠構詞連結的字會標示「字根／字族待確認」，不會臆造字根。
- 原有 3,000 筆詞彙、423 個分類群組、59 堂文法、600 個小單元、10 回線上基礎練習、20 份 PDF 原封保留。現有分類索引提供 3,000 / 3,000 個詞彙入口，但只有約 941 筆已有額外的字根／詞綴／字族群組，其餘目前從情境主題索引。
- 沿用 `toeic-smallsteps-v5` localStorage 鍵，保留原學習進度；URL 不變，無須建立新的 GitHub 儲存庫。

## 分類注意事項

詞庫內的 3,000 筆包含單字與詞組，不是每一筆都能可靠地找到真正字根或衍生字族。第九版分類索引採構詞及字形關係的整理方式，仍可能有需人工校訂的歸類。本版的主要改進是顯示完整數量與實用的分類導覽，**不是宣稱已經替所有 3,000 筆詞彙完成人工語源校訂**。

網站其他功能、發音、雙主題課程、詳細筆記，以及 A4 PDF 練習卷與第九版一致。英文語音仍需裝置瀏覽器支援 Web Speech API；學習進度僅保存在相同瀏覽器的本機儲存空間。
