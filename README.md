# TOEIC 小步學｜第五版：每天一點、越學越多

## 第五版的學習理念

不是減少教材總量，而是 **一次只學少量、慢慢累積大量**。

- 可查的學習字詞條目：3,000 筆（包含單字與詞組）
- 文法主題：59 堂；正式學習每次只顯示一到兩個小重點
- 每個小單元：5 個新字 → 例句 → 3 題小練習 → 手寫筆記
- 整條單字學習路線：600 個小單元，每次完成一個，進度儲存在本機瀏覽器
- 自編基礎練習卷：10 回、150 題，可線上選答，並可下載 10 份 PDF 題目卷與 10 份 PDF 答案詳解
- 正式多益 Part 1–7 題型尚未開啟，不會要求初學者直接做模擬考

## 如何更新你已發布的 GitHub Pages

目前網站：https://coco11465002.github.io/toeic-learning/
儲存庫：https://github.com/coco11465002/toeic-learning

1. 將這個 ZIP 解壓縮（不要只上傳 ZIP）。
2. 在原本的 `toeic-learning` Repository 中，確定目前分支是 `main`。
3. 將這個資料夾內所有檔案，以及完整的 `papers` 資料夾，上傳到儲存庫根目錄；同名檔案以新版內容取代。
4. 確認 GitHub Pages 在 `Settings → Pages` 中仍設定為 `Deploy from a branch`、`main`、`/(root)`。
5. 提交更新後，等待 GitHub Pages 部署。若看到舊畫面，請強制重新整理或開無痕視窗。

**注意：** `index.html` 必須直接位於儲存庫根目錄，`papers` 為其下的子資料夾，例如 `papers/01_questions.pdf`。

## 檔案說明

- `index.html`：首頁、導覽列與網站容器。
- `styles.css`：柔和多彩小卡、手機版排版、手寫筆記外觀。
- `app.js`：學習流程、按鈕、單字詳解、線上練習與進度儲存。
- `data.js`：3,000 筆單字／詞組資料。
- `curriculum.js`：59 堂文法主題教材。
- `papers-data.js`：10 回自編練習卷的 150 道題目。
- `papers/`：PDF 題目及詳解，共 20 份。
- `LICENSE-ECDICT.txt`：英中字典部分資料的來源及授權條款。

## 使用與限制

- 不需要登入帳號；課程與 PDF 在 GitHub Pages 直接使用。
- 英文朗讀依賴裝置與瀏覽器的 Web Speech 語音引擎，無法保證每台手機都有相同口音或支援全部語音。
- 學習進度保存在 **同一台裝置、同一個瀏覽器的 localStorage**，不會自動跨手機和電腦同步。更新網站通常不會刪除相同版本的進度，但從第四版升級到第五版使用新記錄方式，舊版進度不保證繼承。
- 拆分是拼字輔助記憶，不等於正式音標、真實語源字根，且仍有必要進行字詞音節的人工校訂。
- 部分單字目前只有常見搭配、詞性、中文或短語，尚未逐筆配齊完整而獨立的真實情境例句；若無可靠翻譯，介面會標示「中文說明待補」，避免編造。
- 部分詞條的中文定義來自 ECDICT 開放字典，必須逐步校訂語境和詞性。原始教材中如有翻譯不自然或錯誤，以後續校訂版為準。
- 所有基礎練習卷為自行編寫的學習題，不是 ETS 官方題，也不是考古題。正式 TOEIC 題型教學會在基礎學習完成後再另行規劃。
